# 演示素材

这些素材于 2026-09-13 从实际运行的 DroidPane 1.0.0 中采集。

- 桌面环境：macOS，Apple Silicon。
- 演示设备：Android 13 / API 33，ARM64，Pixel 5 虚拟设备配置。
- 连接方式：Android Emulator，经 ADB 连接 DroidPane。
- 设备内容：全新模拟器的系统设置和通知栏，未登录个人账号。
- 应用内录制参数：1080p、8 Mbps、设备音频。
- 实际生成的录屏：498 × 1080，H.264 + AAC，约 41 秒；已在 DroidPane 视频库回放。

| 文件 | 内容 |
| --- | --- |
| `mirroring.png` | 镜像、录制参数和设备控制面板 |
| `recording.png` | 录制中的计时、状态和停止按钮 |
| `video-library.png` | 实际录屏的缩略图、文件信息和回放界面 |
| `droidpane-demo.mp4` | 约 92 秒桌面操作演示，1440 × 1024，30 FPS，H.264 |
